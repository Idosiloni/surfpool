# Surf Pool Sim

First-person wave pool manager sim (CaseOh-style, like Supermarket Simulator / TCG Card Shop Simulator).
Unity 6000.6.6f1, URP, single-player, Mac first (Windows/Steam later). Design + roadmap: `docs/DESIGN.md`.

## Working rules
- Ido is the game designer and playtester; Claude writes code and drives the Editor.
- Each milestone must end playable. One feature per session.
- Drive the live Editor (Unity MCP `unity-editor`, or `unity command` via `~/.unity/bin/unity`) — check `unity status` first. Never hand-edit `.unity` / `.prefab` / `.asset` YAML while an Editor is connected.
- If the Editor won't connect, check for Safe Mode (compile errors) with `unity pipeline list`, fix the C#, restart.
- Art style: low-poly cartoon. 3D models are built by `tools/blender/build_models.py` (people parts in `build_characters.py`, surfboards in `build_boards.py`; both borrow its helpers) (run it in Blender via the Blender MCP: `exec(open(path).read(), ns)`), exported as FBX to `Assets/_Game/Models/`. A Blender point (x, y, z) lands in Unity at (-x, z, -y); `WorldArt.Model()` adds the 180° yaw. World dressing, sky, lighting and post-processing live in `Assets/_Game/Editor/WorldArt.cs`.
- Fake the wave (animated mesh + Shader Graph, surfers follow a path) — no fluid simulation.
- Scripts live in `Assets/_Game/Scripts/`, scenes in `Assets/_Game/Scenes/`.
- UI is UI Toolkit: layout in `Assets/_Game/UI/*.uxml`, all styling in `Assets/_Game/UI/Game.uss` (no inline styles except per-frame positions/bar widths), controllers in `Assets/_Game/Scripts/UI/`. Player messages go through `Notifications.Post(...)` (toasts; pass a `Notice` kind: Info/Good/Reward/Bad). Look = "Sunset Surf Shop" (rules + color tokens in `:root` at the top of `Game.uss`; fonts Lilita One = titles/numbers/buttons, Fredoka = text, Pacifico = little taglines only, all OFL in `UI/Fonts`). Windows pop in with `UiMotion.Show(overlay)` instead of removing `.hidden`. UI art (backdrop, poster, patterns) = `tools/ui/make_ui_art.py` -> `UI/Art/`, icons = `tools/ui/make_icons.py`.
- `Pool.unity` is generated by `Assets/_Game/Editor/GreyboxBuilder.cs` (menu Surf Pool > Build Greybox Scene). Rebuilding overwrites manual scene edits — check `git status` for scene changes first, and fold anything Ido changed by hand back into the builder.
- Agent playtests: focus the Editor first (`editor_focus`) or Play mode won't tick; turn off `EditorSettings.asyncShaderCompilation` while capturing (cyan = shaders not compiled yet) and turn it back on after. Simulated keys don't reach the game — call `Interact()` via eval instead.
- Research notes from the `game-researcher` agent live in `docs/research/`. Read the relevant ones before designing a new step.
- Commit every `.cs`/asset together with its `.meta`. Never commit `Library/`, `Temp/`, `Logs/`, `UserSettings/`.
- Explain things to Ido in plain words; Ido is learning.
- Systems map: pools = `PoolArea` (+ `PoolRegistry`), built by `GreyboxBuilder.BuildPool`; surfers pick a pool via `SurferSpawner.ChoosePool`. Missions in `MissionManager.BuildStory()`. Upgrades in `UpgradeShop` (wave upgrades go through `ApplyWaveUpgrade` for every pool). Save = `SaveSystem` (JSON in persistentDataPath; menu Surf Pool > Delete Save Game). Park-wide modifiers in `ParkEffects`. Prices: session = base price x skill (`PriceBoard.SkillMultiplier`) x pool (`PoolArea.priceMultiplier`); fair/rental prices are rebuilt from owned upgrades (only the base price is saved). Pool size stages: `PoolArea.SetStage` (main pool, Pool Expansion upgrades), basins built per stage by `GreyboxBuilder.BuildBasin`. The Cove = two PoolAreas (`pool_cove`) built by `Editor/CoveBuilder.cs`: a pier of modules (`CovePier`) between a normal half (rights) and a half turned 180 deg (lefts); the east `WaveMachine` leads (`twin`), the west one follows (`leader`), each with a `fixedDirection`. The Surf Ranch (`pool_ranch`, `Editor/RanchBuilder.cs`) = a 45x200 strip, the visible foil carriage = `RanchFoil`; `WaveMachine.minCooldown`/`maxSetSize`, `WaveWater.headStart`/`breakAtMultiplier`, one-way pools seat surfers at the takeoff end (`WaveWater.TakeoffX`/`PeelStartZ`). Wave look: breaking by age (`WaveWater.Age`/`Row`/`Col`/`Sample`, shared by LocalHeight/Foam/UpdateSurface), vertex G = height up the wave for the face gradient in `StylizedWater.shader`, XL sizes = `WaveSize` (`WaveMachine.bigWaves`, `WaveWater.SizeOf`). Pools can be placed/turned (`PoolSpec.x0`/`yaw`): pool code must work in the water's own frame (`water.transform` x = machine->beach, z = across), never world x/z. Pools are WIDE so rides go left/right down the line (research: docs/research/wave-pools-and-ocean-waves.md): main pool stages 40x30 -> 50x40 -> 60x50 (`PoolLength`/`PoolWidth`; south wall fixed at `MainSouth` = -12, it grows north; north-deck dressing is placed from `MainNorth`), with `travel` 0.6, `peel` 1.9 and `peakFromWall` 3 (the break starts 3 m from a side wall at every stage). One connected basin (growing pool slice 1): main pool, a 12 m `Pier` north (grandstand), the Big Wave zone (`pool_lagoon`, 60x52 at `LagoonZ`) beyond it, a sandbar east (`SandbarWest/East`, surfer lanes `InLane`/`OutLane`), the Reef (60x52, `ReefX0`, yaw 180) across it, the Cove north of the Reef (`CoveX/CoveZ`), the Ranch strip east (`RanchX`); walkers use the spine `SpineZ`. `PoolSpec.southDeck/northDeck/eastDeck` are in the pool's own frame. The flat park sand is cut from `Shore.FlatRects` minus `GreyboxBuilder.WaterRects`; after layout changes run Surf Pool > Check Layout (`LayoutCheck.Report()`, must be all 0, incl. shore problems). The island around the park = `Editor/Shore.cs`: outside `FlatRects` a heightfield (`Shore.Height`/`Inland` = meters from the waterline) with dunes, beach, wet sand, sea floor, grassy dune backs (vertex A, drawn by `Shaders/Ground.shader`), a `Sea Wall` collider knee-deep, the ocean's shallows/foam vertex colors, `FarIslands` on the horizon and `Dress` (palm groves, dune grass, bushes, sand fence, driftwood from `tools/blender/build_nature.py`). Anything standing outside the park uses `Shore.Height`; boat routes = `GlowUpBuilder.BoatRoutes` (Shore keeps water open along them), treasure spots = `TreasureBuilder.Places` (Shore keeps beach around them). Sky = `Shaders/StylizedSky.shader` (horizon = fog color; DayCycle dusk lerps `_SkyTint`/`_Exposure` and the fog color). Big pools use `PoolSpec.gridDensity` 2.5. Beach ends are sand crescents: `PoolSpec.beachCorner` (ellipse radii, per stage `stageCorners` -> `PoolArea.SizeStage.beachCorner` -> `WaveWater.Resize`), built by `GreyboxBuilder.BuildBeach`; anything that keeps riders/junk in the water uses `WaveWater.HalfWidthAt(x)`/`ShoreAt(z)`, not Width/2. Edge looks per zone = `PoolLook` (`EdgeMaterials`/`EdgeDressing`, no colliders). Water that no camera sees skips its mesh update (`WaveWater.Update`). `WaveWater.UpdateSurface` is the fast per-frame surface (row/column caches; keep it in sync with `LocalHeight`/`Foam`). Balance numbers and the curve: `docs/BALANCE.md`. Running costs (power per wave, daily water, tax) = `OperatingCosts`, paid in `DayCycle.EndDay`. Park XP/levels = `ParkLevel` (upgrade `level` gates). Level previews = `LevelRoadmap`; perks = `ParkPerks` (own multipliers read at use sites; picks = level/2 - chosen; saved as ids) shown by `UI/PerkPicker`; the goal strip follows the mission's `Objective.upgradeId` (`GameHud.PlanUpgrade`). Breakdowns = `MachineService` on each machine. Staff stars live in `StaffMember` (call `RecordWork`/`TimeFactor` from job scripts). Litter = `Trash`, cleaned by `Janitor`. Daily events = `DailyEvents` (only multiplies its own statics; read them where used), plus daily wind (`DailyEvents.TodayWind`, `WindChop`/`WindRideQuality`/`WindWipeouts`). Title screen = `MainMenu` (pauses the game; `SkipNextTime` for reloads), settings = `GameSettings` + `SettingsScreen`. Snack bar = `SnackBar` (own line; surfers get `WalkingToSnack`/`InSnackLine` states). Build mode = `BuildMode` (B) with `DecorCatalog`/`Decoration` (prefabs made by `Editor/DecorBuilder.cs`); beach guests = `BeachGuests`/`BeachGuest` using `WalkRouter`; treasures = `Treasure` (placed by `Editor/TreasureBuilder.cs`). Fishing = `FishingSpot`, parking/cars = `ParkingLot` (both built in `Editor/ParkExtras.cs`). Daily challenges = `DailyChallenges` (stat deltas from `GameStats`). How a board moves on a wave = `SurfMotion` (shared by `PlayerSurfing` and `Surfer`): heading + speed on the face (`Face` 0 trough..1 lip, measured from the water each step; dropping = speed, climbing = height; the wave's push trims you hands-off; flats/whitewater bog you), all in the water's frame; NPCs steer it with `Surfer.Pilot` (per skill: trim / S-turns / tight pocket + stall, moves are real lines, cut back toward the break when far out or at a wall); player A/D = turn the board (`SteerOverride` + = A = turn left), `TrimAssist` when hands off. Test bench = `Editor/SurfLab` (Rider/Wave/Player/Record/Dump, traces + frames). Riding feel (board tilt on the wave face, lean, rail spray) = `RideFeel` (`BodyTilt` = what the body follows), shared by `Surfer` and `PlayerSurfing`; poses + crossfades + pop-up in `CharacterRig` (riding inputs: Goofy, Style, Crouch, Lean, Air, Twist, ArmsUp, Sprint, BoardTilt; Straddle = sitting on the board in the lineup); NPC maneuvers = `Surfer.Move`. Surfer personalities (grom, kook, charger...) and their lines = `SurferPersonalities` (`Surfer.Type`); gestures (claim, shaka, stretch...) = `CharacterRig.PlayGesture`, heads turn with `CharacterRig.LookTarget`. Player surf scoring (pop-up grade, flow, combos, wipeout hit) lives in `PlayerSurfing`; its HUD (flow bar, combo, call-outs, lens drops, score card) is `UI/SurfHud.cs`, listening to PlayerSurfing events. Park glow-up = `ParkGlowUp` shows/hides every `GlowItem` (fromLevel/untilLevel/requires) from `ParkLevel.Level` + owned upgrades, and swaps worn/fresh paint materials; nothing saved, it's derived. Dressing, crowd, birds (`Bird`), boats/blimp/heli (`Cruiser`), speakers (`ParkSpeaker`) and celebration particles are built by `Editor/GlowUpBuilder.cs`. Luxury tiers = `ParkGlowUp.TierFor(GameStats.TotalEarned)` (`TierEarnings`; `GlowItem.fromTier/untilTier`; tier paint `tierPaint`; pools glow after dark via per-renderer `_PoolGlow` + `DayCycle.Darkness`), props/textures by `Editor/LuxuryBuilder.cs` (placed last, only on free deck; `DeckSet` = loungers -> cabana / fire pit), models by `tools/blender/build_luxury.py`. Deck and coping boxes get world-meter UVs in `GreyboxBuilder.Box`. Celebrations (fireworks, confetti, fanfare, `Celebration.Shown` -> HUD banner) = `Celebration`, fired only by `ParkLevel.LeveledUp` and `UpgradeShop.Bought` (never by loading). Counter shops = `ShopCounter` subclasses (`AcaiBar`, `GearShop` = upgrade `surf_shop`, `BoardShaper`) with `ShopStation`s (tubs, racks, stand) and a `ShopRegister` collider; customers = `Shopper` (spawned per shop by `ShopCustomers`), order bubbles + ticket = `UI/ShopHud`; built by `Editor/ShopBuilder.cs`, models by `tools/blender/build_shops.py` (also the machine parts). The visible wave machine = `WaveMachineRig` (listens to `WaveMachine.WaveFired`), built per pool by `Editor/MachineBuilder.cs`; upgrade-only props = `GlowItem.requires` in `Editor/UpgradeProps.cs`. People: `CharacterLook` + `CharacterLooks` (outfits painted in material bands, prints from `tools/art/make_patterns.py`, signature look per `Archetype`), applied by `CharacterRig.Wear`; faces (6 expressions + blink) in `CharacterRig.UpdateFace`; parts from `tools/blender/build_characters.py`; check looks with Surf Pool > Spawn Look Lineup (Play mode). Voices (babble/shouts/mumbles) = `Voices` with clips `voice_*` from make_sounds.py. Legends = `FamousSurfers` roster + `FamousVisits` (level 15+, `Surfer.MakeFamous`). The story ends with Uncle Kai = `FamousSurfers.Kai` (not in the roster): mission `kai_home` sets `FamousVisits.KaiExpected`, his goodbye sets `KaiHome` and opens `StoryScreen.ShowEnding()`. Missions: `Mission.mail` (Mail letter when it starts, {0} = park name), `Mission.whileActive`. Day end: at 8 PM `DayCycle` closes the gates (`DayCycle.Open` gates every spawner), guests `GoHome`, dusk; the day ends when you flip `ParkSign` at the desk after everyone left. Instant replay = `SurfReplay` (records joint rotations of the player rig at 30 Hz onto the `ReplayAvatar` stand-in; `WaveWater` has its own replay clock `Now`/`Dt` so waves rewind too; plays at timeScale 0). Park name = `ParkName` (saved; empty = old save, asked once), chosen on the `ParkNamer` card after Uncle Kai's letter or at the gate sign (`GateSign`, rename fee); sign texts showing it carry a `NameSign` (format like "WELCOME TO {0}"). Surfer first names = `SurferNames`; each surfer fills a `Visit` diary (wait, barrels, wipeouts, drop-ins, spent) and `ParkReviews.Record` turns it into a starred review when they leave; the day report shows `ParkReviews.Highlights()` + `Facts()` (today only, not saved). Rush hour = `SurfRush` (surf-camp bus, `Surfer.MakeCamper`, HUD `rushPill`, tip via Wallet "surf camp"). Bad customers = `RuleBreakers`: sneak-ins from day 2 (`Surfer.MakeSneaker`), wave hogs and litterbugs from day 3 (`Surfer.MakeRude`, `Surfer.Rudeness`), shoplifters at an open gear shop (`Shopper.MakeShoplifter`, sent via `ShopCustomers.SendShoplifter`); `ThrowOut` kicks any of them, whistle from up to 30 m via `PlayerInteractor.FarSurfer`. Kook rescue = `KookRescue` (beginner wipeout -> `Surfer.InTrouble`, 25 s), ring posts `RescuePost` (built in `UpgradeProps.BuildRescuePosts`, models RescueRing/RescuePost in build_shops.py), thrown `FlyingRing`; a hired lifeguard throws after 6 s. Player surfing camera: chase cam (default, `GameSettings.ChaseCam`, V toggles) shows `SurfReplay`'s live stand-in; moves are gated by the wave's level (`WaveWater.LevelOf`) for the player and NPCs (`Surfer.DoTrick`); test hooks `SteerOverride`/`SpinOverride`/`GrabOverride`/`Pump()`/`TryAir()`. Snapped boards = `BoardBreak` (runtime mesh cut into `BrokenHalf`s; NPC sale via an open `GearShop`, rental loss, player spare board; `ForceNext` for tests). Dirty pools = `PoolDirt` (spawns floating `PoolDebris`, ducks, `PoolRobot`s when upgrade `pool_robot` is owned; `MoodPenalty(pool)` in `Surfer.FinishRide`), skimmer = `SkimmerRack` (+ `PlayerInteractor.FarDebris`), built in `UpgradeProps.BuildPoolDirt`. Wave settings on the console (`WaveControlScreen`): level, direction (+ `WaveMachine.Alternate`), `WaveShape` (Mellow/Standard/Hollow, `WaveWater.SpawnWave` reshapes the type; NPCs react in `Surfer` catch code), set size (`WaveMachine.ChooseSetSize`), famous presets. Your quiver = `SurfQuiver` (`BoardKind` Shortboard/Foamie/Longboard/Fish: speed, allowed moves, pearl, pump cap, take-off window; saved), switched at `QuiverRack` by the main surf peg (`UpgradeProps.BuildQuiverRack`); longboard hang ten = `PlayerSurfing.NoseRide` + `CharacterRig.NoseWalk`; models in build_boards.py. Surf photographer = `PhotoTower` (upgrade `photo_tower`; lens camera, `Grade()` scores moment/centering/size/skill, S shots go on `PhotoWall`, surfers buy their best print via `PhotoTower.SellPrint` when they leave happy), built in `UpgradeProps.BuildPhotoSpot`. Agent screenshots from any point: `EditorTools.DevShots.Shot(path, from, lookAt)` via eval. Sound = `Sfx.Play(Sound.X, position)` (clips in `SoundBank`, generated WAVs from `tools/audio/make_sounds.py` -> `Assets/_Game/Audio/`; re-run the script, then rebuild the scene).
- HUD rule (`docs/research/hud-less-is-more.md`): always on = money, level, clock, one mission line. New HUD info gets a `GameHud.Reveal` (pops in on a rare event, always shown while Alt peek / J journal: `Expanded`), a world object, or a menu tab, never a permanent card. `GameHud.PeekOverride` = test hook for Alt.
- UI helpers: `UiWipe.Play(action)` (wave wipe, lives in the Settings document), `UiAccess` (UI size / reduce motion / colorblind marks from `GameSettings`), `Tooltip.Attach(root)` + element `tooltip` text, `Notifications.Log` (Mail tab; `Post(msg, kind, keep: false)` for chatter), `IInteractable.CanUse` (sandy prompt + shake), `CameraShake.From/Add` (scaled by the shake setting). Accessibility settings live in PlayerPrefs, shared with Ido's real game: restore any you change in a test.
- Perf: `tools/test/perf_park.sh` (inside play_begin/play_end) builds a level-30 park and prints the slowest scripts; `WaveWater` has profiler markers per step and its vertex loop runs in parallel (`SurfaceRows`: no Unity objects in there).
- Agent playtests: ALWAYS start with `tools/test/play_begin.sh` and end with `tools/test/play_end.sh`. They move Ido's real save aside and put it back (a marker file makes play_end a no-op unless play_begin ran). Never delete `surfpool_save.json` any other way, and never use Surf Pool > Delete Save Game during agent work. (A hand-rolled script once deleted Ido's save.)
