# Surf Pool Sim

First-person wave pool manager sim (CaseOh-style, like Supermarket Simulator / TCG Card Shop Simulator).
Unity 6000.6.6f1, URP, single-player, Mac first (Windows/Steam later). Design + roadmap: `docs/DESIGN.md`.

## Working rules
- Ido is the game designer and playtester; Claude writes code and drives the Editor.
- Each milestone must end playable. One feature per session.
- Drive the live Editor (Unity MCP `unity-editor`, or `unity command` via `~/.unity/bin/unity`) — check `unity status` first. Never hand-edit `.unity` / `.prefab` / `.asset` YAML while an Editor is connected.
- If the Editor won't connect, check for Safe Mode (compile errors) with `unity pipeline list`, fix the C#, restart.
- Art style: low-poly cartoon. 3D models are built by `tools/blender/build_models.py` (people parts in `build_characters.py`, surfboards in `build_boards.py`; both borrow its helpers) (run it in Blender via the Blender MCP: `exec(open(path).read(), ns)`), exported as FBX to `Assets/_Game/Models/`. A Blender point (x, y, z) lands in Unity at (-x, z, -y); `WorldArt.Model()` adds the 180° yaw. World dressing, sky, lighting and post-processing live in `Assets/_Game/Editor/WorldArt.cs`.
- Fake the wave (animated mesh + Shader Graph, surfers follow a path) — no fluid simulation.
- Scripts live in `Assets/_Game/Scripts/`, scenes in `Assets/_Game/Scenes/`.
- UI is UI Toolkit: layout in `Assets/_Game/UI/*.uxml`, all styling in `Assets/_Game/UI/Game.uss` (no inline styles except per-frame positions/bar widths), controllers in `Assets/_Game/Scripts/UI/`. Player messages go through `Notifications.Post(...)` (toasts; pass a `Notice` kind: Info/Good/Reward/Bad). Look = "Sunset Surf Shop" (rules + color tokens in `:root` at the top of `Game.uss`; fonts Lilita One = titles/numbers/buttons, Fredoka = text, Pacifico = little taglines only, all OFL in `UI/Fonts`). Windows pop in with `UiMotion.Show(overlay)` instead of removing `.hidden`. UI art (backdrop, poster, patterns) = `tools/ui/make_ui_art.py` -> `UI/Art/`, icons = `tools/ui/make_icons.py`.
- `Pool.unity` is generated by `Assets/_Game/Editor/GreyboxBuilder.cs` (menu Surf Pool > Build Greybox Scene). Rebuilding overwrites manual scene edits — check `git status` for scene changes first, and fold anything Ido changed by hand back into the builder.
- Agent playtests: focus the Editor first (`editor_focus`) or Play mode won't tick; turn off `EditorSettings.asyncShaderCompilation` while capturing (cyan = shaders not compiled yet) and turn it back on after. Simulated keys don't reach the game — call `Interact()` via eval instead.
- Research notes from the `game-researcher` agent live in `docs/research/`. Read the relevant ones before designing a new step.
- Commit every `.cs`/asset together with its `.meta`. Never commit `Library/`, `Temp/`, `Logs/`, `UserSettings/`.
- Explain things to Ido in plain words; Ido is learning.
- Systems map: pools = `PoolArea` (+ `PoolRegistry`), built by `GreyboxBuilder.BuildPool`; surfers pick a pool via `SurferSpawner.ChoosePool`. Missions in `MissionManager.BuildStory()`. Upgrades in `UpgradeShop` (wave upgrades go through `ApplyWaveUpgrade` for every pool). Save = `SaveSystem` (JSON in persistentDataPath; menu Surf Pool > Delete Save Game). Park-wide modifiers in `ParkEffects`. Prices: session = base price x skill (`PriceBoard.SkillMultiplier`) x pool (`PoolArea.priceMultiplier`); fair/rental prices are rebuilt from owned upgrades (only the base price is saved). Pool size stages: `PoolArea.SetStage` (main pool, Pool Expansion upgrades), basins built per stage by `GreyboxBuilder.BuildBasin`. Each pool has its own size (`PoolSpec.length/width`; Reef 75x36 at `ReefZ`, Lagoon 75x48 at `LagoonZ`) plus `travel` (wave speed) and `peakOffset` (break starts near the wall) for long rides. Balance numbers and the curve: `docs/BALANCE.md`. Running costs (power per wave, daily water, tax) = `OperatingCosts`, paid in `DayCycle.EndDay`. Park XP/levels = `ParkLevel` (upgrade `level` gates). Level previews = `LevelRoadmap`; perks = `ParkPerks` (own multipliers read at use sites; picks = level/2 - chosen; saved as ids) shown by `UI/PerkPicker`; the goal strip follows the mission's `Objective.upgradeId` (`GameHud.PlanUpgrade`). Breakdowns = `MachineService` on each machine. Staff stars live in `StaffMember` (call `RecordWork`/`TimeFactor` from job scripts). Litter = `Trash`, cleaned by `Janitor`. Daily events = `DailyEvents` (only multiplies its own statics; read them where used). Title screen = `MainMenu` (pauses the game; `SkipNextTime` for reloads), settings = `GameSettings` + `SettingsScreen`. Snack bar = `SnackBar` (own line; surfers get `WalkingToSnack`/`InSnackLine` states). Build mode = `BuildMode` (B) with `DecorCatalog`/`Decoration` (prefabs made by `Editor/DecorBuilder.cs`); beach guests = `BeachGuests`/`BeachGuest` using `WalkRouter`; treasures = `Treasure` (placed by `Editor/TreasureBuilder.cs`). Fishing = `FishingSpot`, parking/cars = `ParkingLot` (both built in `Editor/ParkExtras.cs`). Daily challenges = `DailyChallenges` (stat deltas from `GameStats`). Riding feel (board tilt on the wave face, lean, rail spray) = `RideFeel`, shared by `Surfer` and `PlayerSurfing`; poses + crossfades + pop-up in `CharacterRig` (riding inputs: Goofy, Style, Crouch, Lean, Air, Twist, ArmsUp, Sprint, BoardTilt; Straddle = sitting on the board in the lineup); NPC maneuvers = `Surfer.Move`. Surfer personalities (grom, kook, charger...) and their lines = `SurferPersonalities` (`Surfer.Type`); gestures (claim, shaka, stretch...) = `CharacterRig.PlayGesture`, heads turn with `CharacterRig.LookTarget`. Player surf scoring (pop-up grade, flow, combos, wipeout hit) lives in `PlayerSurfing`; its HUD (flow bar, combo, call-outs, lens drops, score card) is `UI/SurfHud.cs`, listening to PlayerSurfing events. Park glow-up = `ParkGlowUp` shows/hides every `GlowItem` (fromLevel/untilLevel/requires) from `ParkLevel.Level` + owned upgrades, and swaps worn/fresh paint materials; nothing saved, it's derived. Dressing, crowd, birds (`Bird`), boats/blimp/heli (`Cruiser`), speakers (`ParkSpeaker`) and celebration particles are built by `Editor/GlowUpBuilder.cs`. Celebrations (fireworks, confetti, fanfare, `Celebration.Shown` -> HUD banner) = `Celebration`, fired only by `ParkLevel.LeveledUp` and `UpgradeShop.Bought` (never by loading). Counter shops = `ShopCounter` subclasses (`AcaiBar`, `GearShop` = upgrade `surf_shop`, `BoardShaper`) with `ShopStation`s (tubs, racks, stand) and a `ShopRegister` collider; customers = `Shopper` (spawned per shop by `ShopCustomers`), order bubbles + ticket = `UI/ShopHud`; built by `Editor/ShopBuilder.cs`, models by `tools/blender/build_shops.py` (also the machine parts). The visible wave machine = `WaveMachineRig` (listens to `WaveMachine.WaveFired`), built per pool by `Editor/MachineBuilder.cs`; upgrade-only props = `GlowItem.requires` in `Editor/UpgradeProps.cs`. People: `CharacterLook` + `CharacterLooks` (outfits painted in material bands, prints from `tools/art/make_patterns.py`, signature look per `Archetype`), applied by `CharacterRig.Wear`; faces (6 expressions + blink) in `CharacterRig.UpdateFace`; parts from `tools/blender/build_characters.py`; check looks with Surf Pool > Spawn Look Lineup (Play mode). Voices (babble/shouts/mumbles) = `Voices` with clips `voice_*` from make_sounds.py. Legends = `FamousSurfers` roster + `FamousVisits` (level 15+, `Surfer.MakeFamous`). Day end: at 8 PM `DayCycle` closes the gates (`DayCycle.Open` gates every spawner), guests `GoHome`, dusk; the day ends when you flip `ParkSign` at the desk after everyone left. Instant replay = `SurfReplay` (records joint rotations of the player rig at 30 Hz onto the `ReplayAvatar` stand-in; `WaveWater` has its own replay clock `Now`/`Dt` so waves rewind too; plays at timeScale 0). Park name = `ParkName` (saved; empty = old save, asked once), chosen on the `ParkNamer` card after Uncle Kai's letter or at the gate sign (`GateSign`, rename fee); sign texts showing it carry a `NameSign` (format like "WELCOME TO {0}"). Surfer first names = `SurferNames`; each surfer fills a `Visit` diary (wait, barrels, wipeouts, drop-ins, spent) and `ParkReviews.Record` turns it into a starred review when they leave; the day report shows `ParkReviews.Highlights()` + `Facts()` (today only, not saved). Surf photographer = `PhotoTower` (upgrade `photo_tower`; lens camera, `Grade()` scores moment/centering/size/skill, S shots go on `PhotoWall`, surfers buy their best print via `PhotoTower.SellPrint` when they leave happy), built in `UpgradeProps.BuildPhotoSpot`. Agent screenshots from any point: `EditorTools.DevShots.Shot(path, from, lookAt)` via eval. Sound = `Sfx.Play(Sound.X, position)` (clips in `SoundBank`, generated WAVs from `tools/audio/make_sounds.py` -> `Assets/_Game/Audio/`; re-run the script, then rebuild the scene).
- Agent playtests: ALWAYS start with `tools/test/play_begin.sh` and end with `tools/test/play_end.sh`. They move Ido's real save aside and put it back (a marker file makes play_end a no-op unless play_begin ran). Never delete `surfpool_save.json` any other way, and never use Surf Pool > Delete Save Game during agent work. (A hand-rolled script once deleted Ido's save.)
